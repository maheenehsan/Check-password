# Check-passworod
## About the Project
This is a beginner-friendly Python program that checks the strength of a password based on selected criteria.
## Features
- Takes a password as input from the user.
- Checks password length.
- Checks for uppercase and lowercase letters.
- Checks for digits and special characters.
- Displays a password-strength result.
## Requirements
- Python 3
## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the Python file using:
python password_checker.py`
